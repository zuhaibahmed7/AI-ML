## Getting Started

Most notebooks in this repository are designed to run on [Google Colab](https://colab.research.google.com/). Click the **Open in Colab** badge at the top of each notebook to launch it directly.

### Prerequisites

- A Google account (for Colab)
- A [Google AI Studio](https://aistudio.google.com/) API key (for notebooks that use Gemini models)

## Topics Covered

- **Multi-Agent Systems** – Designing and orchestrating multiple AI agents using Google ADK
- **Large Language Models (LLMs)** – Leveraging Gemini models for conversational AI and task automation
